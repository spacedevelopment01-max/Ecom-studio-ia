## Région, formats, tarifs et limites

Alibaba résout ici la région **`intl` (Singapour)** ; aucun endpoint personnalisé ou workspace n’est présent. Les autres adaptateurs utilisent leurs endpoints natifs ; région/organisation/quota de compte non vérifiés. Le modèle vidéo imposé demande 1080P sans son ; les autres formats/durées doivent être validés par les capacités du modèle réellement sélectionné, pas par les dimensions finales du montage.

Le code inclut des tailles Qwen (carré, 4:5, 9:16, 16:9 et autres), des tailles natives OpenAI 1024² / 1536×1024 / 1024×1536 et des recadrages locaux. Cela ne prouve pas que chaque référence, format vendu ou durée est accepté par chaque modèle. Les références essentielles excédant la capacité du modèle provoquent un refus, pas leur suppression. Le mode vidéo direct convertit actuellement certains aspects vers 9:16/16:9 à l’appel ; carré/4:5 restent à vérifier sur les fichiers reçus et après montage.

La date administrative de confirmation des prix est absente dans la configuration contrôlée. Le catalogue embarque des références documentaires et tarifs datés, notamment Alibaba du 15/10/2026, **pas revalidés officiellement pendant ce diagnostic**. Aucun tarif officiel actuel, quota ou droit modèle ne doit être déduit des commentaires. Le budget client et le plafond d’une campagne de test n’ont pas été interrogés sur un projet réel.
