# Métadonnées de fichiers : phrases naturelles

Quatre défauts reproduits (4 rouges /20anciens verts) : renommage sans guillemets, renommage poli, déplacement vers un nom unique sans guillemets, déplacement poli avec question. Le routage normalise ces formulations puis réutilise exactement la sélection sauvegardée et le moteur changeFileMetadata existant. Aucune action implicite et aucun ciblage du premier fichier.

Le nom non délimité est accepté seulement s’il est non vide,≤200caractères,sans guillemets incomplets,saut de ligne ou conjonction de commande. Un nom exact délimité peut contenir «et» et reste une donnée littérale. Demandes chaînées ou mal délimitées donnent une clarification sans proposition. Dossiers homonymes/étrangers, sélection/version/fingerprint, forfait/drapeau,A1 et reprise conservent leurs contrôles acquis. Aucun octet ni version de contenu régénéré.
