# Contrôle fiable du minimum de 17 secondes

Échec observé : PR #380 / run 41807018751 / job 126496473606, étape sections natives, encre-telephone-services, suppression. L'assertion « attente réelle » échoue après le retour du minuteur, avant tout clic d'accord. Le Docker et la suite complète de ce run passent. Le même parcours est vert dans les contrôles obligatoires #381, #382 et #383. Aucun défaut de persistance applicative démontré par cet échec.

Le harnais utilisait un unique waitForTimeout(17000) puis Date.now()-since>=17000. Un retour légèrement anticipé ou une variation de l'horloge civile suffit à faire échouer cette mesure ; le log ne permet pas de départager ces causes. Le correctif mesure performance.now() et attend le reliquat jusqu'à un minimum monotone effectif de 17000 ms. La valeur minimale, l'assertion, le clic d'accord, la relecture du résultat natif et les quatre parcours restent obligatoires. Le harnais Image utilise le même helper. Aucun workflow, garde financier, code applicatif ou interface n'est modifié.
