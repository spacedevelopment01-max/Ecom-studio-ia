# Havane (maroquinerie) : défauts notés pendant l'essai, pour le lot de fin

Défauts relevés sans arrêter l'essai (règle du budget de 5 € en tout, 27 novembre 2026).

1. **Noms** : « Patine » écarté à la vérification avec la raison « le même secteur que ton projet de vêtements » ; le
   client fait de la maroquinerie (la raison se trompe de métier). Corrigé depuis sur evolution-sina (b719269), selon le
   chef d'orchestre.
2. **Noms** : « 0 parole(s) réelle(s) de clients trouvée(s) » malgré trois recherches sur le web payées.
3. **Esquisses, tour de remplacement** : deux cases sans le nom « HAVANE » (seulement un H) marquées « correcte, mais
   pas nécessaire » ; sans effet ici (non montrées), à vérifier que le contrôle du nom exact vaut aussi au remplacement.
4. **Planche A, essai 2** (refusée à tort) : la phrase du logo « SACS · PORTEFEUILLES · CEINTURES » est aussi la liste
   des produits ; le code compte comme « phrase mal écrite » la colonne de l'ouverture « SACS / PORTEFEUILLES /
   CEINTURES » et le titre de référencement « Havane – Sacs · Portefeuilles · Ceintures en cuir ». Le relecteur disait
   « phrase du client juste partout » (8,5/10). Planche jugée montrable par le chef d'orchestre.
5. **Planche A, essai 1** : domaine lu en double (« havanefrance.fr / havanefrance.fr — disponible ») ; phrase écrite
   en double sur la boîte kraft (« … / … ») ; à vérifier si c'est un vrai défaut du dessin ou une lecture doublée.
