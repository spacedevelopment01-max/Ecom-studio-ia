## Parcours et frontière des preuves

Chaque projet possède dix publications et dix publicités, chacune affectée à son ratio propre : 4 carrés + 3 portraits feed + 3 stories dans chaque ensemble. Les quatre carrés publicitaires sont destinés à Facebook ; les trois portraits à Instagram feed. Les preuves UI vérifient ces deux compteurs, le devis global, le rangement, les fichiers et la reprise. Les vingt entrées du plan synthétique sont différentes ; les images de harnais utilisent un rendu déterministe volontairement étiqueté. Elles ne démontrent pas la diversité artistique attendue de vrais modèles.

Les tests vérifient séparément le refus du même concept dans trois ratios, les paraphrases identifiées par la revue sémantique, une publicité visuellement dupliquée depuis un organique et sa seule correction. Le contrôleur réel reçoit les buffers de la candidate et de toutes les créations acceptées ; son jugement réel reste à tester. Les identités et sources de ces projets sont fictives.

Le navigateur part de l’ancien parcours documenté ; il confirme le contexte depuis l’interface, obtient et accepte le devis global, puis ouvre les créations dans les vrais onglets. La création native de nouveaux projets et les validations du parcours Préparation sont couvertes par les tests API et moteur, pas prétendues comme réalisées par ces vidéos. Les crédits du compte de preuve sont factices et suivent la règle native 50 % HT. Aucun paiement, compte social ou clé client.
